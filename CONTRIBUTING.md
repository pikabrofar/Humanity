# Contributing

Thanks for helping! Issues and pull requests are welcome.

- **Sign off your commits** (`git commit -s`). This certifies the
  [Developer Certificate of Origin](https://developercertificate.org/): you wrote
  the change or have the right to submit it under the MIT License.
- Don't paste code from projects with incompatible licenses, and don't add
  dependencies without noting their license in `THIRD_PARTY_NOTICES.md`.
- Keep data on the Mac: no telemetry, no servers, and no new network calls without
  updating `PRIVACY.md`.
- Never add features designed for covert recording or tracking of other people.
- Run `make test` in every package you touch.

Don't post license keys, or builds that unlock the official apps, in issues or
pull requests. Building from source is free and needs no key.
