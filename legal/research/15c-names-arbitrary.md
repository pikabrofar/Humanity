## Top 5 (best first)

1. **Teasel** (Low). The only candidate with no commercial software and no App Store or Mac hit, and teasel.app shows no DNS. Two syllables ("TEE-zel"), easy to spell and say. A spiky plant, which is a pleasant but unusual image. Only GitHub hits are two tiny hobby/research repos. Weakness: "tease" sounds slightly playful; spelling could be "teazel" by ear. Modules read well: Teasel Eyes / Hands / Voice.
2. **Larkspur** (Med). Pleasant, no identified Mac software or app of the same name. The risk is crowding: "Lark" (ByteDance's Lark Suite, which runs on macOS) is close in sound and look, and larkspur.com and larkspur.app are both taken. Three syllables. Needs a proper trademark search.
3. **Bittern** (Med). Distinct, unusual bird name. No Mac app found, but Bittern Technologies is a software dev agency (services, class 42 overlap) and both main domains are taken. "Bitter" is a slightly negative association.
4. **Willet** (Med). Easy to say, short. Some GitHub dev tools and an ecommerce company use the name, and it sounds like "wallet" and "will it". Domains taken.
5. **Sorrel** (Med). Nice sound and sorrel.app looks unregistered. Conflict: an agent-native version-control tool of that name with a macOS desktop app (early alpha, so it may or may not survive) and a Sorrel Studio iOS app. Tolerable only if the VCS project stays tiny; check it.

Rejected for crowded same-field use: Tamarack, Yarrow, Sumac, Fennel, Kestrel, Cairn, Plover.

## Notes
- Real-word names are crowded. Even the survivors need USPTO classes 9/42/38 searches, a check of EUIPO/UKIPO, and an App Store name search done by hand.
- "No DNS records" does not mean a domain is available (it could be registered but unused); confirm with a registrar.
- Searches were English-only snippets; the meaning check in other languages was limited to what I know (no obvious problems for Teasel).
